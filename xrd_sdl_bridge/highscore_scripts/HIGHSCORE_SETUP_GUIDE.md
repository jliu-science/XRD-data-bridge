# HighScore Plus + ICDD Auto-Import & Search & Match Setup Guide

This guide explains how to connect `.xrdml` / `.asc` files generated by **XRD SDL Bridge** with **Malvern Panalytical HighScore Plus** (linked to your **ICDD PDF** database) for one-click or automated phase identification.

---

## Option 1: One-Click User Batch Button (Recommended for Daily Single-PC Use)

### Step 1: Save 3 Parameter Sets (Requires one `.xrdml` or `.asc` open in HighScore)
1. **Background (`My_BG`)**:
   - Open `Treatment -> Determine Background...`
   - Click `More >>` (bottom-right), click the **Save (floppy disk)** icon, name it `My_BG`, and close.
2. **Peak Search (`My_Peaks`)**:
   - Open `Treatment -> Search Peaks...`
   - Adjust minimum significance as desired, click `More >>` -> **Save**, name it `My_Peaks`, and close.
3. **ICDD Search & Match (`My_ICDD_SM`)**:
   - Open `Analysis -> Search & Match -> Execute Search & Match...`
   - Under the `Restrictions` tab, click `Edit Restriction Set...`, select your ICDD subfiles (e.g., `Inorganic`) and/or allowed elements, then close back to Search & Match.
   - Click `More >>` -> **Save**, name it `My_ICDD_SM`, and close.

### Step 2: Create the One-Click User Batch Button (`Auto_ICDD`)
1. Go to `Customize -> Edit User Batches...` (or `Edit Smart Batches...` in newer versions).
2. Click `New Batch...` and name it `Auto_ICDD`.
3. Add these steps in order:
   1. `Determine Background` (`My_BG`)
   2. `Search Peaks` (`My_Peaks`)
   3. `Execute Search & Match` (`My_ICDD_SM`)
   4. *(Optional)* `Export_SDL_Phase_CSV` (if you want CSV reports sent back to the bridge UI)
4. Ensure `Interactive / Show Dialog` is **unchecked** for unattended execution, and `Show in Toolbar` is checked.
5. Make sure the **Batches** toolbar is visible (`View -> Toolbars -> Batches` or right-click any toolbar). You can now click **`Auto_ICDD`** right after opening any `.xrdml` from the bridge!

---

## Option 2: Fully Automatic on Open (Optional)
1. *(Optional)* In `Customize -> Script IDE`, import `auto_search_match_icdd.pas`, update `OutDir` to match your `highscore_results\` folder, and save as a User Script Parameter Set.
2. Go to `Customize -> Program Settings -> Automatic Processing` and assign your Batch (`Auto_ICDD`).
3. Enable **"Auto-open .xrdml in HighScore Plus"** in the XRD SDL Bridge UI. Whenever a new `.xrdml` is generated, HighScore Plus will launch and execute your ICDD Search & Match batch automatically.

---

## Why `.xrdml` is Preferred Over `.asc`
- **`.asc`** (2-column `2Theta \t Intensity`) drops X-ray tube metadata, forcing HighScore to assume Cu radiation unless changed manually in Object Inspector.
- **`.xrdml`** (XML v1.3) preserves `<usedWavelength>` ($K\alpha_1, K\alpha_2, K\beta$), kV/mA, step size, and sample ID cleanly for both HighScore Plus and PANalytical Data Viewer.
- **XRD SDL Bridge** generates **both `.asc` and `.xrdml`** while keeping your original `.hdf5` and `.xy` files 100% read-only and untouched.
